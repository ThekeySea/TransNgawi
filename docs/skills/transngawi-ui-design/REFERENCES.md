# References — TransNgawi UI Design Skill

Skill ini adalah sintesis project-specific dari prinsip-prinsip yang relevan di repository resmi Meng To.

Source repository: https://github.com/MengTo/Skills

## Fondasi utama

- `ui/design-first-ui-prompting` — design-first specification, constraints, hierarchy, typography/spacing, variation dan iteration.
- `web-design/build-awwwards-quality-sites` — art direction, reference analysis, original identity, asset discipline, accessibility dan performance QA.
- `web-design/animation-systems` — purpose-driven motion, duration/easing, choreography, transform/opacity dan reduced motion.
- `web-design/image-first-grid-layout` — full-bleed imagery, image-first composition, overlays, grid dan deliberate cropping.
- `web-design/editorial-tech` — hierarchy, asymmetrical composition, structural lines, restrained accent dan quiet surfaces.
- `web-design/progressive-blur` — controlled blur, layering dan performance caution.
- `web-design/beautiful-shadows` — neutral elevation dan layered shadow discipline.
- `web-design/split-layout-technical` — disciplined split layouts, framing dan metadata hierarchy.
- `web-design/webgl-landing-steering` — WebGL hanya jika justified, dengan fallback/performance gates dan conversion clarity.
