# TransNgawi Documentation Bundle

This bundle contains the project-level documentation, agent instructions, and OpenCode skills.

## Important

`AGENTS.md` is intended to be the single root agent-instruction file. If Laravel Boost generates a newer `AGENTS.md`, preserve the current Boost-specific generated guidance and merge the TransNgawi rules from this bundle into it rather than blindly overwriting Boost's generated file.

The project documentation belongs under `docs/`.

OpenCode skills belong under `.opencode/skills/`.
